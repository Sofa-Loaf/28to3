The problem

macOS and Windows minutes are easy to run up and hard to explain.

Private-repo teams find out after finance asks, or after a macOS job or a wide Windows matrix quietly eats the plan’s included minutes. There is no built-in “which job did this?” view at the moment a run finishes.

1 min Minimum charge, even for a 12-second job
2× Windows multiplier vs Linux included minutes
10× macOS multiplier vs Linux included minutes

Who it’s for

Private repos with macOS or a wide Windows matrix.

Surprise bills, not Linux-only

macOS jobs or a wide Windows matrix on private repos — retries, a quota reset, and a bill nobody can explain. If you are Linux-only, or you already run GitHub’s enterprise Billing API, this is not for you.
