What it does

Copy. Paste. Do not execute from here.

Built for a ticket, a jump box, and a paste buffer. Dense NOC chrome. Dark and light. Command lists scroll inside the window. No remote shell, no cloud sync, no account.

Clipboard only

Copy filled or raw. Paste into the remote session yourself. No SSH, WinRM, or iLO execution from this app. On purpose.

Tabs and placeholders

Diagnostics, Networking, Troubleshooting, and the rest. {{host}} {{ip}} {{user}} {{port}} plus defaults like {{port:22}}. Last-used values stick.

Stays in the browser

Import JSON, text, Markdown, or YAML. Export the library or the current tab. Dark and light, persisted. Display saves scroll motion (system / smooth / instant) and list density (comfortable / compact) in the same key, command-center:document. No backend.
