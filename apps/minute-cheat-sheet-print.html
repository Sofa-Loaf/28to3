Private-repo Actions bills are a lump sum. This page is the per-job math Actionscope writes into a Job Summary — wall, rounded minutes, SKU, list-price $, included-minute burn.

12 seconds still bills 1 minute

GitHub rounds each started job up to the next whole minute. A 12-second lint is 1 rounded minute. This is not ceil(combined wall). Jobs that never started are 0.

Included-minute burn

Standard hosted runners only: Linux 1× · Windows 2× · macOS 10× per rounded minute. Larger runners cannot use included minutes (burn = 0).

Est. $ = rounded minutes × list rate. Label it an estimate. Source: GitHub Actions runner pricing, 2026-09-05. Public repos, self-hosted, and larger-runner SKUs are out of scope here.

How to read Job Summary columns

  1. Wall time — completed_at − started_at (running jobs use now).
  2. Rounded min — ceil each started job to a whole minute.
  3. Runner SKU — from job labels / runner name; match the usage-report SKU.
  4. Est. $ (list) — rounded min × documented per-minute rate. Not an invoice.
  5. Included min — plan-minute burn: Linux 1, Windows 2, macOS 10.
